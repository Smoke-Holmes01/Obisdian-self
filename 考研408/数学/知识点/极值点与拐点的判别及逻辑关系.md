# 极值点与拐点的判别及逻辑关系

## 一、 概念与定义

### 1. 极值与极值点
设函数 $f(x)$ 在点 $x_0$ 的某个去心邻域 $\mathring{U}(x_0, \delta)$ 内有定义：
- 若对该去心邻域内任意 $x$，均有 $f(x) < f(x_0)$，则称 $f(x_0)$ 为 $f(x)$ 的**极大值**，$x_0$ 称为**极大值点**；
- 若对该去心邻域内任意 $x$，均有 $f(x) > f(x_0)$，则称 $f(x_0)$ 为 $f(x)$ 的**极小值**，$x_0$ 称为**极小值点**。

### 2. 拐点
设曲线 $y = f(x)$ 在区间 $I$ 内连续。若在该曲线上的点 $(x_0, f(x_0))$ 处，曲线的凹凸性发生改变（即从凹弧变成凸弧，或从凸弧变成凹弧），则称平面点 **$(x_0, f(x_0))$** 为曲线的**拐点**。

### 3. 驻点
设函数 $f(x)$ 在 $x_0$ 处可导，若一阶导数为零，即 $f'(x_0) = 0$，则称 $x_0$ 为 $f(x)$ 的**驻点**。

### 4. 疑点对比与必要条件
- **极值必要条件**：若 $f(x)$ 在 $x_0$ 处可导且取得极值，则必有 $f'(x_0) = 0$。
- **拐点必要条件**：若 $f(x)$ 在 $x_0$ 处二阶可导且 $(x_0, f(x_0))$ 为拐点，则必有 $f''(x_0) = 0$。

| 类别 | 候选的疑点（极值/拐点只可能在疑点处取得） |
| :--- | :--- |
| **疑极值点** | 1. 驻点（$f'(x_0) = 0$）<br>2. 一阶导数不存在的点 |
| **疑拐点** | 1. 二阶导数为零点（$f''(x_0) = 0$）<br>2. 二阶导数不存在且函数连续的点 |

## 二、 判别条件与核心定理

### 1. 极值判别法与拐点判别法对称表

| 判别法 | 一元函数极值的充分条件（自变量 $x_0$） | 曲线拐点的充分条件（点 $(x_0, f(x_0))$） |
| :--- | :--- | :--- |
| **第一充分条件** | $f'(x)$ 在 $x_0$ 左右去心邻域内**异号**：<br>- 左正右负：极大值点<br>- 左负右正：极小值点 | $f''(x)$ 在 $x_0$ 左右去心邻域内**异号**：<br>- 左右变号则为拐点 |
| **第二充分条件** | 设 $f'(x_0) = 0$ 且二阶可导：<br>- $f''(x_0) < 0$：极大值点<br>- $f''(x_0) > 0$：极小值点<br>- $f''(x_0) = 0$：失效 | 设 $f''(x_0) = 0$ 且三阶可导：<br>- $f'''(x_0) \neq 0$：拐点<br>- $f'''(x_0) = 0$：失效 |
| **第三充分条件** | 首次不为 0 的是 $n$ 阶导数（$n \ge 2$）：<br>- $n$ 为**偶数**：极值点（结合 $f^{(n)}(x_0)$ 符号判定极大/小）<br>- $n$ 为**奇数**：非极值点 | 首次不为 0 的是 $n$ 阶导数（$n \ge 3$）：<br>- $n$ 为**奇数**：拐点<br>- $n$ 为**偶数**：非拐点 |

### 2. 泰勒公式推导证明（以第二充分条件为例）

#### 极值二阶充分条件推导：
将 $f(x)$ 在驻点 $x_0$ 处进行二阶泰勒展开：
$$f(x) - f(x_0) = f'(x_0)(x - x_0) + \frac{1}{2}f''(x_0)(x - x_0)^2 + o((x - x_0)^2)$$
因 $f'(x_0) = 0$，故：
$$f(x) - f(x_0) = \frac{1}{2}f''(x_0)(x - x_0)^2 + o((x - x_0)^2)$$
在去心邻域内，$(x - x_0)^2 > 0$。根据局部保号性，增量 $f(x) - f(x_0)$ 的正负完全由 $f''(x_0)$ 决定：
- $f''(x_0) < 0 \implies f(x) - f(x_0) < 0 \implies f(x_0)$ 为极大值。
- $f''(x_0) > 0 \implies f(x) - f(x_0) > 0 \implies f(x_0)$ 为极小值。

#### 拐点二阶充分条件推导：
将 $f''(x)$ 在二阶导零点 $x_0$ 处进行一阶泰勒展开（即对 $f(x)$ 的三阶展开）：
$$f''(x) = f''(x_0) + f'''(x_0)(x - x_0) + o(x - x_0)$$
因 $f''(x_0) = 0$，故：
$$f''(x) = f'''(x_0)(x - x_0) + o(x - x_0)$$
因为 $f'''(x_0) \neq 0$，而 $(x - x_0)$ 在 $x_0$ 左右两侧符号相反。根据局部保号性，$f''(x)$ 在 $x_0$ 左右去心邻域必异号，由第一充分条件可知 $(x_0, f(x_0))$ 为拐点。

## 三、 核心概念逻辑关系辨析

### 1. 极值点 vs 驻点
- **极值点不一定是驻点**：极值可以发生在不可导点。例如 $f(x) = |x|$ 在 $x=0$ 处不可导但有极小值。
- **驻点不一定是极值点**：例如 $f(x) = x^3$ 在 $x=0$ 处是驻点（$f'(0)=0$），但其一阶导数在两侧不改变符号（单调递增），故不是极值点。
- **关系结论**：对于**可导函数**，极值点必是驻点（费马定理必要性），驻点是极值点的必要非充分条件。

### 2. 拐点 vs 一阶导数的极值点
- **若一阶导数 $f'(x)$ 连续且有定义**，则二者完全等价：
  $f(x)$ 凹凸性改变（拐点） $\dots f'(x)$ 增减性改变（一阶导数的极值点）。
- **非对称性陷阱（一阶导数不存在时）**：
  若原函数 $f(x)$ 在 $x_0$ 处连续但 $f'(x_0)$ 不存在，原函数在该点仍可能有拐点，但一阶导数因没有定义而不能称为极值点。
  - **经典反例**：$f(x) = x^{\frac{1}{3}}$。
    在 $x=0$ 处，$f(x)$ 连续，其二阶导数 $f''(x) = -\frac{2}{9}x^{-\frac{5}{3}}$ 在 $x < 0$ 时大于 0（凹），$x > 0$ 时小于 0（凸）。因此 **$(0,0)$ 是 $f(x)$ 的拐点**。
    但由于一阶导数 $f'(0)$ 不存在，一阶导数在该点无定义，所以 **$x=0$ 不是一阶导数 $f'(x)$ 的极值点**。

## 四、 典型例题与解析

**例题**：求函数 $f(x) = 3x^5 - 5x^4$ 的极值点与拐点。

**解析过程**：
1. **求一阶与二阶导数**：
   $$f'(x) = 15x^4 - 20x^3 = 5x^3(3x - 4)$$
   $$f''(x) = 60x^3 - 60x^2 = 60x^2(x - 1)$$
2. **极值点判别**：
   令 $f'(x) = 0$ 得驻点 $x_1 = 0$ 和 $x_2 = \frac{4}{3}$。
   - 对 $x_2 = \frac{4}{3}$：$f''\left(\frac{4}{3}\right) = 60\left(\frac{4}{3}\right)^2\left(\frac{4}{3}-1\right) > 0$，故由第二充分条件可知，$x_2 = \frac{4}{3}$ 为**极小值点**。
   - 对 $x_1 = 0$：$f''(0) = 0$（失效）。我们采用第一充分条件：当 $x < 0$ 时 $f'(x) > 0$，当 $0 < x < \frac{4}{3}$ 时 $f'(x) < 0$。一阶导数左右变号（left正right负），故 $x_1 = 0$ 为**极大值点**。
3. **拐点判别**：
   令 $f''(x) = 0$ 得疑拐点 $x_a = 0$ 和 $x_b = 1$。
   - 对 $x_b = 1$：当 $x < 1$ 且接近 1 时 $f''(x) < 0$，当 $x > 1$ 时 $f''(x) > 0$。二阶导数异号，故 $(1, f(1)) = (1, -2)$ 为**拐点**。
   - 对 $x_a = 0$：在 $x=0$ 的左右去心邻域内，由于 $x^2 \ge 0$ 且 $x-1 < 0$，故 $f''(x) = 60x^2(x-1) < 0$ 恒成立。二阶导数不改变符号，故 $(0, f(0)) = (0, 0)$ **不是拐点**。

## 五、 拓展延伸：多项式函数极值点与拐点个数的快速判定（考研秒杀公式）

对于多项式函数：
$$f(x) = (x - a_1)^{n_1}(x - a_2)^{n_2} \cdots (x - a_k)^{n_k}$$
其中 $n_i$ 为正整数，$a_i$ 为两两不等的实数（不妨设 $a_1 < a_2 < \dots < a_k$）。
记：
- $k_1$ 为单根（即 $n_i = 1$）的个数；
- $k_2$ 为偶重根（即 $n_i$ 为大于 1 的偶数）的个数；
- $k_3$ 为奇重根（即 $n_i$ 为大于 1 的奇数）的个数；
- 总根数为 $k = k_1 + k_2 + k_3$。

在函数总次数 $\sum_{i=1}^k n_i \ge 2$ 的前提下，该函数的极值点个数 $M$ 与拐点个数 $N$ 满足以下秒杀公式：

1. **极值点个数**：
   $$M = k + k_2 - 1$$
2. **拐点个数**：
   $$N = k_1 + 2k_2 + 3k_3 - 2$$
   *(若公式算得结果为负，则个数为 0)*

---

### 💡 秒杀公式背后的数学原理推导

#### (1) 极值点个数的推导：
- **根处变号判定**：
  - 每一个偶重根 $a_i$（共 $k_2$ 个），在一阶导数 $f'(x)$ 中对应的因式为 $(x-a_i)^{n_i-1}$，由于 $n_i$ 是偶数，则 $n_i-1$ 是奇数，因此 $f'(x)$ 在 $a_i$ 处**变号**，贡献了 $k_2$ 个极值点。
  - 每一个单根与奇重根（共 $k_1 + k_3$ 个），一阶导数在其根处不改变符号，故在这些根处没有极值点。
- **区间夹击判定（罗尔定理）**：
  - 原函数 $f(x)$ 共有 $k$ 个不同的零点 $a_1 < a_2 < \dots < a_k$，它们将定义域划分为 $k-1$ 个开区间 $(a_i, a_{i+1})$。
  - 根据罗尔定理，在每一个开区间内，$f'(x)$ 必定且仅有一个变号零点，从而贡献了 $k-1$ 个极值点。
- **总数**：$M = (k - 1) + k_2 = k + k_2 - 1$。

#### (2) 拐点个数的推导：
- **根处变号判定**：
  - 每一个奇重根 $a_i$（共 $k_3$ 个，次数 $n_i \ge 3$ 且为奇数），在二阶导数 $f''(x)$ 中对应的因式为 $(x-a_i)^{n_i-2}$。由于 $n_i-2$ 是奇数，所以 $f''(x)$ 在 $a_i$ 左右变号，贡献了 $k_3$ 个拐点。
  - 每一个偶重根 $a_i$（共 $k_2$ 个），$n_i-2$ 是偶数，二阶导数不改变符号，无拐点。单根 $a_i$（共 $k_1$ 个）不是 $f''(x)$ 的零点。
- **区间夹击判定（罗尔定理）**：
  - 一阶导数 $f'(x)$ 的不同零点包括：所有重根 $a_i$（$n_i \ge 2$，共 $k_2 + k_3$ 个），以及相邻两个根之间的 $k-1$ 个一阶导数零点。
  - 因此 $f'(x)$ 共有 $(k_2 + k_3) + (k - 1)$ 个不同的零点。
  - 根据罗尔定理，在这些零点相邻的区间内，二阶导数 $f''(x)$ 必有且仅有一个变号零点（对应拐点），其个数为：
    $$(k_2 + k_3 + k - 1) - 1 = k + k_2 + k_3 - 2$$
- **总数**：
  $$N = k_3 + (k + k_2 + k_3 - 2) = k + k_2 + 2k_3 - 2$$
  代入 $k = k_1 + k_2 + k_3$，即可化简为：
  $$N = k_1 + 2k_2 + 3k_3 - 2$$
