# 常用希腊字母总结

## 一、 考研数学常用希腊字母对照表

| 大写 | 小写 | 英文读音 / 国际音标 | 考研数学中的核心应用 | 易错点与书写规范 |
| :---: | :---: | :--- | :--- | :--- |
| $A$ | $\alpha$ | Alpha /`ˈælfə`/ | **【线代】** 常用作列向量，如 $\alpha_1, \alpha_2$。<br>**【高数】** 表示常数、角度，或用于无穷小量的比较：$\beta = o(\alpha)$。 | **不要写成英文字母 $a$。** 书写 $\alpha$ 时要从右上角起笔，一笔画出，注意尾部的交叉。 |
| $B$ | $\beta$ | Beta /`ˈbiːtə`/ 或 /`ˈbeɪtə`/ | **【线代】** 常表示列向量或方程组的右端常数项 $A\vec{x} = \beta$。<br>**【高数】** 与 $\alpha$ 配对使用表示无穷小量。 | **不要写成英文字母 $b$ 或 $B$。** 它的起笔在下方，向上拉起再写“8”字形的上半部。 |
| $\Gamma$ | $\gamma$ | Gamma /`ˈgæmə`/ | **【线代】** 常表示第三个向量 $\gamma$。<br>**【概率】** 大写 $\Gamma$ 用于 $\Gamma$ 函数 $\Gamma(x)$ 及其分布。 | 小写 $\gamma$ 容易与拼音 $y$ 混淆。书写时注意 $\gamma$ 底部是圆润的弧线，而不是尖角。 |

| $H$ | $\eta$ | Eta /`ˈiːtə`/ | **【线代】** 特别常用于表示齐次或非齐次线性方程组的解向量、基础解系，如 $\eta_1, \eta_2$。 | **极其容易写成英文字母 $n$。** $\eta$ 的左半边要向下拉得很长，以示与 $n$ 的区别。若在答卷中书写模糊，阅卷老师可能会按错符号扣分。 |
| $\Theta$ | $\theta$ | Theta /`ˈθiːtə`/ | **【高数】** 极坐标系中的极角 $\theta$；<br>泰勒公式的拉格朗日余项中表示介于 0 和 1 之间的数：$\xi = x_0 + \theta(x - x_0)$，其中 $0 < \theta < 1$。 | 在多元函数微积分中，化二重积分为极坐标时，**千万不要漏掉极坐标变换中的面积元素 $r dr d\theta$ 中的 $r$**。 |
| $\Lambda$ | $\lambda$ | Lambda /`ˈlæmdə`/ | **【线代】** 特征值 $\lambda$ 及其特征矩阵 $\lambda E - A$；大写 $\Lambda$ 通常表示对角矩阵。<br>**【概率】** 泊松分布 $P(\lambda)$ 中的参数。 | **考研数学一的绝对重难点！** 每年必考特征值与特征向量。大写 $\Lambda$ 底部是开口的，不要写成字母 $\Delta$。 |
| $M$ | $\mu$ | Mu /`mjuː`/ | **【概率】** 表示随机变量的数学期望（均值） $\mu$。 | 书写时左边一竖向下延伸，与英文字母 $u$ 区分开。 |

| $\Sigma$ | $\sigma$ | Sigma /`ˈsɪgmə`/ | **【高数】** 大写 $\Sigma$ 表示级数求和 $\sum_{n=1}^{\infty} u_n$，或表示曲面积分中的积分曲面 $\Sigma$。<br>**【概率】** 小写 $\sigma$ 表示标准差，$\sigma^2$ 表示方差。 | 在概率论中，已知正态分布 $N(\mu, \sigma^2)$ 时，**常考陷阱是给出标准差 $\sigma$，但公式中需要填入方差 $\sigma^2$**，反之亦然。做题时一定要看清已知条件是方差还是标准差。 |

| $\Psi$ | $\psi$ | Psi /`psaɪ`/ | **【高数】** 常用作函数符号 $\psi(x)$，常与 $\phi(x)$ 成对出现。 | 无 |

## 二、 概念定义
希腊字母在考研数学中常用于表示核心的数学对象和概念，包括极限定义的波动区间（如 $\epsilon, \delta$）、中值点（如 $\xi$）、特征值（如 $\lambda$）、向量（如 $\alpha, \beta, \gamma, \eta$）、积分变量或角度（如 $\theta, \varphi$）以及统计量与分布参数（如 $\mu, \sigma, \chi$）。熟练掌握其读音、规范书写及对应的考研数学背景，是数学复习和做题中的基础要求。

## 三、 核心定理与公式
考研数学中常用的希腊字母极其代表的数学公式包括：

1. **极限定义中的逼近控制**：
   对于极限 $\lim_{x \to x_0} f(x) = A$，其 $\epsilon-\delta$ 定义为：
   $$\forall \epsilon > 0, \exists \delta > 0, \text{ 当 } 0 < |x - x_0| < \delta \text{ 时，恒有 } |f(x) - A| < \epsilon$$

2. **微分中值定理中的中值点**：
   - 罗尔定理、拉格朗日中值定理、柯西中值定理中的中值点通常记为 $\xi$。例如拉格朗日中值定理：
     $$f(b) - f(a) = f'(\xi)(b-a), \quad \xi \in (a, b)$$
   - 泰勒公式中拉格朗日余项的表示：
     $$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}, \quad \xi = x_0 + \theta(x - x_0) \ (0 < \theta < 1)$$

3. **线性代数特征值与特征向量**：
   对于矩阵 $A$，其特征值记为 $\lambda$，对应的特征向量记为 $\alpha$（或 $\vec{x}$），满足：
   $$A\alpha = \lambda \alpha \quad (\alpha \neq 0)$$
   特征多项式为：
   $$|\lambda E - A| = 0$$

4. **概率论与数理统计参数**：
   - 正态分布 $X \sim N(\mu, \sigma^2)$：其均值为 $\mu$，方差为 $\sigma^2$，标准差为 $\sigma$。
   - 泊松分布 $X \sim P(\lambda)$：其概率分布为 $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$。
   - 二维正态分布中的相关系数为 $\rho$。
   - 标准正态分布的概率密度函数为 $\varphi(x) = \frac{1}{\sqrt{2\pi}}e^{-\frac{x^2}{2}}$，分布函数为 $\Phi(x)$。
   - 卡方分布：$\chi^2 \sim \chi^2(n)$，其中 $n$ 为自由度。

## 四、 考点与典型题型分析
### 1. 考点分布
- **高数（选择、解答题）**：考察极限的精确定义时，常利用 $\epsilon$ 与 $\delta$ 的定量关系设置干扰项。此外，在微分中值定理的证明大题中，正确书写和代入中值点 $\xi$ 是得分关键。
- **线代（填空、解答题）**：求解矩阵特征值 $\lambda$ 及对应特征向量 $\alpha$，进而对矩阵进行相似对角化（$\Lambda = P^{-1}AP$）。
- **概率（填空、解答题）**：涉及正态分布的计算，常需要利用对称性将 $N(\mu, \sigma^2)$ 标准化为标准正态分布，利用公式 $\Phi(\frac{x-\mu}{\sigma})$ 计算概率，极易因混淆方差 $\sigma^2$ 与标准差 $\sigma$ 而失分。

### 2. 典型例题
**例题（正态分布的应用与易错点）**：
设随机变量 $X \sim N(2, 4)$，求 $P(0 < X < 4)$。

**【解析】**
已知 $X \sim N(\mu, \sigma^2)$，此处 $\mu = 2$，方差 $\sigma^2 = 4$，从而标准差 $\sigma = \sqrt{4} = 2$。
将 $X$ 标准化得：
$$P(0 < X < 4) = P\left(\frac{0 - 2}{2} < \frac{X - 2}{2} < \frac{4 - 2}{2}\right) = P\left(-1 < Y < 1\right)$$
其中 $Y \sim N(0,1)$。
利用标准正态分布函数的对称性：
$$P(-1 < Y < 1) = \Phi(1) - \Phi(-1) = \Phi(1) - [1 - \Phi(1)] = 2\Phi(1) - 1$$
查表可得 $\Phi(1) \approx 0.8413$，则：
$$P(0 < X < 4) = 2 \times 0.8413 - 1 = 0.6826$$

**【常见陷阱】**
极易把已知条件 $X \sim N(2, 4)$ 中的 $4$ 误认为是标准差 $\sigma$。如果错误代入 $\sigma=4$，则会得出 $P(\frac{0-2}{4} < Y < \frac{4-2}{4}) = P(-0.5 < Y < 0.5) = 2\Phi(0.5)-1$ 的错误结果。复习时必须时刻警惕正态分布参数的含义。
