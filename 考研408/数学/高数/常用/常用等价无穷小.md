# 常用的等价无穷小替换

> [!note]
> 等价无穷小替换是求极限问题中最基础、最高效的化简手段。合理利用等价替换可以大幅缩减运算步骤。

---

## 一、 基本概念

若 $\lim_{x \to x_0} f(x) = 0$ 且 $\lim_{x \to x_0} g(x) = 0$，且满足下式：
$$\lim_{x \to x_0} \frac{f(x)}{g(x)} = 1$$
则称 $f(x)$ 与 $g(x)$ 在 $x \to x_0$ 时是**等价无穷小**，记作：
$$f(x) \sim g(x) \quad (x \to x_0)$$

> [!important] 核心用途
> 求极限时，将复杂的无穷小因子替换为简单的等价无穷小，达到化简计算的目的。

> [!warning] 替换边界条件
> 等价无穷小替换**一般只在乘除法中直接使用**。在加减法中，除非被替换项与整体不是同阶抵消，否则不能随意替换（否则容易导致丢失精度或计算错误，需配合泰勒公式处理）。

---

## 二、 $x \to 0$ 时的等价无穷小

### 1. 基础等价关系

| 序号 | 原始函数 | 等价形式 | 备注与约束条件 |
| :---: | :--- | :--- | :--- |
| 1 | $\sin x$ | $\sim x$ | 最基本三角函数 |
| 2 | $\tan x$ | $\sim x$ | |
| 3 | $\arcsin x$ | $\sim x$ | |
| 4 | $\arctan x$ | $\sim x$ | |
| 5 | $\ln(1+x)$ | $\sim x$ | |
| 6 | $e^x - 1$ | $\sim x$ | |
| 7 | $a^x - 1$ | $\sim x \ln a$ | 指数推广，$a>0$ |
| 8 | $1 - \cos x$ | $\sim \dfrac{1}{2}x^2$ | 二阶无穷小 |
| 9 | $(1+x)^\alpha - 1$ | $\sim \alpha x$ | 二项式推广，$\alpha \in \mathbb{R}$ |
| 10 | $x - \sin x$ | $\sim \dfrac{1}{6}x^3$ | 泰勒展开推导 |
| 11 | $\tan x - x$ | $\sim \dfrac{1}{3}x^3$ | |
| 12 | $x - \ln(1+x)$ | $\sim \dfrac{1}{2}x^2$ | |
| 13 | $e^x - 1 - x$ | $\sim \dfrac{1}{2}x^2$ | |
| 14 | $\arctan x - x$ | $\sim -\dfrac{1}{3}x^3$ | |

### 2. 常用三角函数组合等价
- $\sin x \sim \tan x \sim \arcsin x \sim \arctan x \sim x$
- $\ln(1+x) \sim e^x - 1 \sim x$
- $1 - \cos x \sim \dfrac{x^2}{2}$

### 3. 常用根式展开等价形式（源自公式 9）

| 展开式 | 等价形式 | 参数条件 |
| :--- | :--- | :--- |
| $\sqrt{1+x} - 1$ | $\sim \dfrac{1}{2}x$ | $\alpha = \frac{1}{2}$ |
| $\sqrt[3]{1+x} - 1$ | $\sim \dfrac{1}{3}x$ | $\alpha = \frac{1}{3}$ |
| $\dfrac{1}{\sqrt{1+x}} - 1$ | $\sim -\dfrac{1}{2}x$ | $\alpha = -\frac{1}{2}$ |
| $\sqrt[n]{1+x} - 1$ | $\sim \dfrac{1}{n}x$ | $\alpha = \frac{1}{n}$ |

---

## 三、 推广形式（取极限时趋于 0 的整体）

令 $\square$ 代表取极限时**趋于 0** 的任意表达式（可以是自变量 $x$，也可以是复合函数 $g(x)$）：
- $\sin \square \sim \square$
- $\tan \square \sim \square$
- $\ln(1+\square) \sim \square$
- $e^\square - 1 \sim \square$
- $1 - \cos \square \sim \dfrac{1}{2}\square^2$
- $(1+\square)^\alpha - 1 \sim \alpha \square$

---

## 四、 $x \to 0^+$ 时的无穷大比较（阶数）

当 $x \to 0^+$ 时，增长速度（趋于无穷大快慢）满足以下顺序关系：
$$e^{\frac{1}{x}} \gg x^{-\alpha} \gg \ln^n x \quad (\alpha > 0)$$

---

## 五、 $x \to \infty$ 时的等价无穷大增长速度

当 $x \to +\infty$ 时，不同类型函数发散到正无穷的速度等级为：
$$\ln x \ll x^\alpha \ll a^x \ll x! \ll x^x \quad (\alpha>0,\ a>1)$$

---

## 六、 使用技巧与经典例题

### 1. 乘除法中直接替换
在极限乘除运算中，无穷小因子可以直接进行替换：
$$\lim_{x\to 0} \frac{\sin x \cdot \tan x}{x^2} = \lim_{x\to 0} \frac{x \cdot x}{x^2} = 1$$

### 2. 加减法中谨慎替换

> [!warning] 错误示例
> 计算 $\lim_{x\to 0} \dfrac{\sin x - \tan x}{x^3}$ 时，若直接将分子替换为 $\sin x \sim x$、$\tan x \sim x$，则分子相减为 $0$，丢失了高阶项精度，得出错误结果。

> [!example] 正确示例：利用高阶等价公式
> 利用已知的差值等价关系：$\sin x - \tan x = \sin x (1 - \sec x) \sim x \left(-\frac{1}{2}x^2\right) = -\frac{1}{2}x^3$。
> 故极限为：
> $$\lim_{x\to 0} \frac{\sin x - \tan x}{x^3} = \lim_{x\to 0} \frac{-\frac{1}{2}x^3}{x^3} = -\frac{1}{2}$$

### 3. 配合洛必达法则
在处理未定式 $\frac{0}{0}$ 或 $\frac{\infty}{\infty}$ 时，通常先用等价无穷小进行局部化简，然后再对简化的式子使用洛必达法则求导，可以避开复杂的导数计算，事半功倍。
