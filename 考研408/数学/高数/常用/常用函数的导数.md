# 常用函数的导数公式

> [!note]
> 本篇笔记汇总高等数学微积分中所有基础初等函数、双曲函数的导数公式，以及求导运算法则与常用高阶导数公式。

---

## 一、 基本初等函数导数

| 函数 $f(x)$ | 导数 $f'(x)$ | 适用范围与说明 |
| :---: | :---: | :--- |
| $C$（常数） | $0$ | 任意常数 |
| $x^a$ | $a \cdot x^{a-1}$ | 幂函数，$a \in \mathbb{R}$ |
| $e^x$ | $e^x$ | 自然指数函数 |
| $a^x$ | $a^x \ln a$ | 指数函数，$a>0, a\neq 1$ |
| $\ln x$ | $\dfrac{1}{x}$ | 对数函数，$x>0$ |
| $\ln\vert x\vert$ | $\dfrac{1}{x}$ | 复合对数形式，$x \neq 0$ |
| $\log_a x$ | $\dfrac{1}{x \ln a}$ | 对数函数，$a>0, a\neq 1, x>0$ |
| $\sin x$ | $\cos x$ | 正弦函数 |
| $\cos x$ | $-\sin x$ | 余弦函数 |
| $\tan x$ | $\sec^2 x = \dfrac{1}{\cos^2 x}$ | 正切函数，$x \neq \frac{\pi}{2}+k\pi$ |
| $\cot x$ | $-\csc^2 x = -\dfrac{1}{\sin^2 x}$ | 余切函数，$x \neq k\pi$ |
| $\sec x$ | $\sec x \tan x$ | 正割函数 |
| $\csc x$ | $-\csc x \cot x$ | 余割函数 |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$ | 反正弦函数，$\vert x\vert<1$ |
| $\arccos x$ | $-\dfrac{1}{\sqrt{1-x^2}}$ | 反余弦函数，$\vert x\vert<1$ |
| $\arctan x$ | $\dfrac{1}{1+x^2}$ | 反正切函数 |
| $\operatorname{arccot} x$ | $-\dfrac{1}{1+x^2}$ | 反余切函数 |

## 二、 双曲函数导数

| 函数 $f(x)$ | 导数 $f'(x)$ | 定义式 |
| :---: | :---: | :--- |
| $\sinh x$ | $\cosh x$ | 双曲正弦：$\frac{e^x - e^{-x}}{2}$ |
| $\cosh x$ | $\sinh x$ | 双曲余弦：$\frac{e^x + e^{-x}}{2}$ |
| $\tanh x$ | $\operatorname{sech}^2 x = 1 - \tanh^2 x$ | 双曲正切：$\frac{\sinh x}{\cosh x}$ |

## 三、 求导法则

### 1. 四则运算求导法则
- **加减法**：$(u \pm v)' = u' \pm v'$
- **常数倍**：$(Cu)' = Cu'$ （$C$ 为任意常数）
- **乘法**：$(uv)' = u'v + uv'$
- **除法**：$\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2} \quad (v \neq 0)$

### 2. 复合函数求导（链式法则）
若 $y = f(u)$ 且 $u = g(x)$，则复合函数 $y = f[g(x)]$ 对 $x$ 的导数为：
$$\frac{dy}{dx} = f'[g(x)] \cdot g'(x)$$
> [!tip] 记忆口诀
> **外层求导数，里层照样写，最后乘以内层导。**

### 3. 反函数求导法则
若 $y = f(x)$ 的反函数为 $x = f^{-1}(y)$，则在 $f'(x) \neq 0$ 处：
$$[f^{-1}(y)]' = \frac{1}{f'(x)}$$
或者写为：
$$\frac{dx}{dy} = \frac{1}{\frac{dy}{dx}}$$

### 4. 隐函数求导法
对于方程 $F(x,y)=0$ 定义的隐函数，求导时方程两边同时对自变量 $x$ 求导（视 $y$ 为 $x$ 的复合函数），再解出 $y'$ 的表达式。

### 5. 参数方程求导法则
若曲线由参数方程 $\begin{cases} x = x(t) \\ y = y(t) \end{cases}$ 给出，则一阶导数为：
$$\frac{dy}{dx} = \frac{y'(t)}{x'(t)} \quad (x'(t) \neq 0)$$
二阶导数为：
$$\frac{d^2y}{dx^2} = \frac{d}{dx}\left(\frac{dy}{dx}\right) = \frac{\frac{d}{dt}\left(\frac{dy}{dx}\right)}{x'(t)} = \frac{\left(\frac{y'(t)}{x'(t)}\right)'}{x'(t)}$$

### 6. 对数求导法
对于幂指函数 $y = f(x)^{g(x)}$ 或极其复杂的连乘、连除分式，先两边取自然对数：
$$\ln y = g(x) \ln f(x)$$
然后两边同时对 $x$ 求导：
$$\frac{y'}{y} = [g(x) \ln f(x)]' \implies y' = y \cdot [g(x) \ln f(x)]'$$

## 四、 常用高阶导数公式

| 函数 | $n$ 阶导数 $f^{(n)}(x)$ |
| :---: | :--- |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x (\ln a)^n$ |
| $\sin x$ | $\sin\left(x + \frac{n\pi}{2}\right)$ |
| $\cos x$ | $\cos\left(x + \frac{n\pi}{2}\right)$ |
| $x^m$ | $m(m-1)\cdots(m-n+1)\,x^{m-n}$ （当 $n > m$ 时，导数为 $0$） |
| $\ln x$ | $(-1)^{n-1}\,(n-1)!\,x^{-n}$ |
| $\dfrac{1}{x}$ | $(-1)^n\,n!\,x^{-(n+1)}$ |
| $\dfrac{1}{x+a}$ | $(-1)^n\,n!\,(x+a)^{-(n+1)}$ |
