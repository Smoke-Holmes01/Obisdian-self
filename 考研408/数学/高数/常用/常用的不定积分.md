# 常用的不定积分公式

> [!note]
> 本篇笔记汇总高等数学微积分中常用的不定积分公式，包括基本积分公式以及 24 个考研常考的不定积分公式。本笔记仅包含公式，不作推导。

---

## 一、 基本不定积分公式

| 序号  |        被积函数 $f(x)$        |    不定积分 $\int f(x) \mathrm{d}x$    | 备注                |
| :-: | :-----------------------: | :--------------------------------: | :---------------- |
|  1  |            $0$            |                $C$                 |                   |
|  2  |           $x^a$           |     $\dfrac{x^{a+1}}{a+1} + C$     | $a \neq -1$       |
|  3  |      $\dfrac{1}{x}$       |       $\ln\vert x\vert + C$        | $x \neq 0$        |
|  4  |           $a^x$           |      $\dfrac{a^x}{\ln a} + C$      | $a > 0, a \neq 1$ |
|  5  |           $e^x$           |             $e^x + C$              |                   |
|  6  |         $\sin x$          |           $-\cos x + C$            |                   |
|  7  |         $\cos x$          |            $\sin x + C$            |                   |
|  8  |        $\sec^2 x$         |            $\tan x + C$            |                   |
|  9  |        $\csc^2 x$         |           $-\cot x + C$            |                   |
| 10  |      $\sec x \tan x$      |            $\sec x + C$            |                   |
| 11  |      $\csc x \cot x$      |           $-\csc x + C$            |                   |
| 12  |         $\tan x$          |     $-\ln\vert\cos x\vert + C$     |                   |
| 13  |         $\cot x$          |     $\ln\vert\sin x\vert + C$      |                   |
| 14  |         $\sec x$          | $\ln\vert\sec x + \tan x\vert + C$ |                   |
| 15  |         $\csc x$          | $\ln\vert\csc x - \cot x\vert + C$ |                   |
| 16  |    $\dfrac{1}{1+x^2}$     |          $\arctan x + C$           |                   |
| 17  | $\dfrac{1}{\sqrt{1-x^2}}$ |          $\arcsin x + C$           |                   |
| 18  |         $\sinh x$         |           $\cosh x + C$            |                   |
| 19  |         $\cosh x$         |           $\sinh x + C$            |                   |

## 二、 24个经典不定积分公式

|  序号  | 积分表达式                                                     | 积分结果（公式）                                                                                                                                                                                                                                                                                                                                                                                                 | 适用条件                 |
| :--: | :-------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------- |
| (1)  | $\int \cos^3 x \mathrm{d}x$                               | $\sin x - \dfrac{1}{3} \sin^3 x + C$                                                                                                                                                                                                                                                                                                                                                                     |                      |
| (2)  | $\int \sin^3 x \mathrm{d}x$                               | $-\cos x + \dfrac{1}{3} \cos^3 x + C$                                                                                                                                                                                                                                                                                                                                                                    |                      |
| (3)  | $\int \sec x \mathrm{d}x$                                 | $\ln\vert\sec x + \tan x\vert + C$                                                                                                                                                                                                                                                                                                                                                                       |                      |
| (4)  | $\int \sec^3 x \mathrm{d}x$                               | $\dfrac{1}{2} \sec x \tan x + \dfrac{1}{2} \ln\vert\sec x + \tan x\vert + C$                                                                                                                                                                                                                                                                                                                             |                      |
| (5)  | $\int \dfrac{1}{a^2 - x^2} \mathrm{d}x$                   | $\dfrac{1}{2a} \ln\left\vert \dfrac{a+x}{a-x} \right\vert + C$                                                                                                                                                                                                                                                                                                                                           | $a \neq 0$           |
| (6)  | $\int \dfrac{1}{x^2 - a^2} \mathrm{d}x$                   | $\dfrac{1}{2a} \ln\left\vert \dfrac{x-a}{x+a} \right\vert + C$                                                                                                                                                                                                                                                                                                                                           | $a \neq 0$           |
| (7)  | $\int \dfrac{1}{a^2 + x^2} \mathrm{d}x$                   | $\dfrac{1}{a} \arctan \dfrac{x}{a} + C$                                                                                                                                                                                                                                                                                                                                                                  | $a \neq 0$           |
| (8)  | $\int \dfrac{1}{a^2 + (x+b)^2} \mathrm{d}x$               | $\dfrac{1}{a} \arctan \dfrac{x+b}{a} + C$                                                                                                                                                                                                                                                                                                                                                                | $a \neq 0$           |
| (9)  | $\int \dfrac{1}{a^2 - (x+b)^2} \mathrm{d}x$               | $\dfrac{1}{2a} \ln\left\vert \dfrac{a+x+b}{a-(x+b)} \right\vert + C$                                                                                                                                                                                                                                                                                                                                     | $a > 0$              |
| (10) | $\int \dfrac{1}{(x+b)^2 - a^2} \mathrm{d}x$               | $\dfrac{1}{2a} \ln\left\vert \dfrac{x+b-a}{x+b+a} \right\vert + C$                                                                                                                                                                                                                                                                                                                                       | $a > 0$              |
| (11) | $\int \dfrac{1}{\sqrt{x^2 - a^2}} \mathrm{d}x$            | $\ln\left\vert x + \sqrt{x^2 - a^2} \right\vert + C$                                                                                                                                                                                                                                                                                                                                                     | $a > 0$              |
| (12) | $\int \dfrac{1}{\sqrt{a^2 - x^2}} \mathrm{d}x$            | $\arcsin \dfrac{x}{a} + C$                                                                                                                                                                                                                                                                                                                                                                               | $a > 0$              |
| (13) | $\int \dfrac{1}{\sqrt{x^2 + a^2}} \mathrm{d}x$            | $\ln\left\vert x + \sqrt{x^2 + a^2} \right\vert + C$                                                                                                                                                                                                                                                                                                                                                     | $a > 0$              |
| (14) | $\int \csc^3 x \mathrm{d}x$                               | $-\dfrac{1}{2} \csc x \cot x + \dfrac{1}{2} \ln\vert\csc x - \cot x\vert + C$                                                                                                                                                                                                                                                                                                                            |                      |
| (15) | $\int \tan^2 x \mathrm{d}x$                               | $\tan x - x + C$                                                                                                                                                                                                                                                                                                                                                                                         |                      |
| (16) | $\int \tan^3 x \mathrm{d}x$                               | $\dfrac{1}{2} \tan^2 x + \ln\vert\cos x\vert + C$                                                                                                                                                                                                                                                                                                                                                        |                      |
| (17) | $\int \tan^4 x \mathrm{d}x$                               | $\dfrac{1}{3} \tan^3 x - \tan x + x + C$                                                                                                                                                                                                                                                                                                                                                                 |                      |
| (18) | $\int \cot^3 x \mathrm{d}x$                               | $-\dfrac{1}{2} \cot^2 x - \ln\vert\sin x\vert + C$                                                                                                                                                                                                                                                                                                                                                       |                      |
| (19) | $\int \dfrac{\cos x}{1 + \sin x} \mathrm{d}x$             | $\ln(1 + \sin x) + C$                                                                                                                                                                                                                                                                                                                                                                                    |                      |
| (20) | $\int \dfrac{1}{a^2 \sin^2 x + b^2 \cos^2 x} \mathrm{d}x$ | $\dfrac{1}{ab} \arctan \left( \dfrac{a \tan x}{b} \right) + C$                                                                                                                                                                                                                                                                                                                                           | $a \neq 0, b \neq 0$ |
| (21) | $\int \dfrac{1}{\sin 2x} \mathrm{d}x$                     | $\dfrac{1}{2} \ln\vert\tan x\vert + C$                                                                                                                                                                                                                                                                                                                                                                   |                      |
| (22) | $\int \dfrac{1}{\cos 2x} \mathrm{d}x$                     | $\dfrac{1}{2} \ln\vert\sec 2x + \tan 2x\vert + C$                                                                                                                                                                                                                                                                                                                                                        |                      |
| (23) | $\int \dfrac{1}{a + b \cos x} \mathrm{d}x$                | <ul><li>当 $a > b > 0$ 时：<br>$\dfrac{2}{\sqrt{a^2-b^2}} \arctan \left( \sqrt{\dfrac{a-b}{a+b}} \tan \dfrac{x}{2} \right) + C$</li><li>当 $b > a > 0$ 时：<br>$\dfrac{1}{\sqrt{b^2-a^2}} \ln \left\vert \dfrac{\sqrt{b+a} + \sqrt{b-a} \tan \frac{x}{2}}{\sqrt{b+a} - \sqrt{b-a} \tan \frac{x}{2}} \right\vert + C$</li><li>当 $a = b > 0$ 时：<br>$\dfrac{1}{a} \tan \dfrac{x}{2} + C$</li></ul>                | $a > 0, b > 0$       |
| (24) | $\int \dfrac{1}{a + b \sin x} \mathrm{d}x$                | <ul><li>当 $a > b > 0$ 时：<br>$\dfrac{2}{\sqrt{a^2-b^2}} \arctan\left(\dfrac{a \tan \frac{x}{2} + b}{\sqrt{a^2-b^2}}\right) + C$</li><li>当 $b > a > 0$ 时：<br>$\dfrac{1}{\sqrt{b^2-a^2}} \ln\left\vert \dfrac{a \tan \frac{x}{2} + b - \sqrt{b^2-a^2}}{a \tan \frac{x}{2} + b + \sqrt{b^2-a^2}} \right\vert + C$</li><li>当 $a = b > 0$ 时：<br>$-\dfrac{2}{a\left(\tan \frac{x}{2} + 1\right)} + C$</li></ul> | $a > 0, b > 0$       |
