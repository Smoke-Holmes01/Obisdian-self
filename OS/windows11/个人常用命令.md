## 1. Conda 环境配置

| 用途 | 命令 | 备注 |
| :--- | :--- | :--- |
| 初始化 Conda 到 PowerShell | `conda init powershell` | 修改 [[powershell 7.x|PowerShell]] 启动配置文件 |
| 移除 PowerShell 初始化 | `conda init --reverse powershell` | 撤销并还原终端加载 Conda 基础环境配置 |

## 4. Git 本地与远程同步

针对本地项目的快捷推送和上游分支绑定：

```powershell
# 1. 初始化本地 Git 仓库
git init

# 2. 暂存所有变更文件
git add .

# 3. 提交并记录提交说明
git commit -m "feat: init project"

# 4. 重命名默认主分支为 main
git branch -M main

# 5. 关联 GitHub 远程仓库
git remote add origin https://github.com/<你的用户名>/<仓库名>.git

# 6. 推送并绑定本地分支与远程上游分支
git push -u origin main
```

| 用途 | 命令 | 备注 |
| :--- | :--- | :--- |
| 推送至远程 master 分支 | `git push origin master` | 仅在远程仓库默认分支仍为 `master` 时使用 |

## 5. WSL 备份与还原

WSL (Windows Subsystem for Linux) 发行版的本地快速备份与路径迁移操作：

```powershell
# 1. 导出正在运行的 Ubuntu 发行版为 tar 备份包
wsl --export Ubuntu wsl-ubuntu-backup.tar

# 2. 导入备份包到新的安装目录，并重命名为 Ubuntu
wsl --import Ubuntu <安装路径目录> wsl-ubuntu-backup.tar
```

> [!tip]
> 导入时请选择一个未创建的全新路径目录。如果需要强制指定为 WSL 2 容器类型，可在导入命令末尾追加参数 `--version 2`。
