# Ubuntu 常用命令与 API 调用调试

> [!note]
> 本篇笔记汇总 Ubuntu 环境下的包管理（APT）、服务诊断命令，以及开发中高频使用的 API 调用与调试技巧（如 curl + jq 命令）。

---

## 一、 软件包管理（APT）

Ubuntu 默认使用 APT 软件包管理器：

```bash
# 1. 更新本地包索引（安装软件前推荐运行）
sudo apt update

# 2. 安装指定的软件包
sudo apt install -y curl jq build-essential

# 3. 卸载指定的软件包（保留配置文件）
sudo apt remove package-name

# 4. 彻底卸载软件包（清除配置文件）
sudo apt purge package-name

# 5. 升级系统中所有可升级的包
sudo apt upgrade
```

---

## 二、 系统诊断与服务控制

```bash
# 1. 使用 systemd 管理服务
sudo systemctl start ssh       # 启动服务
sudo systemctl stop ssh        # 停止服务
sudo systemctl restart ssh     # 重启服务
sudo systemctl status ssh      # 查看运行状态
sudo systemctl enable ssh      # 设置开机自启

# 2. 查看系统日志（通过 journalctl）
journalctl -u ssh -n 50        # 查看 ssh 服务的最近 50 行日志
journalctl -xe                 # 查看最近的系统引导/报错信息
```

## 三、 网络调试与 API 测试

在开发中，经常需要通过终端直接测试 HTTP API，尤其是在测试本地或局域网内的模型接口服务。

### 1. 通用云端大模型 API 测试

使用 `curl` 命令行工具，并配合 `jq` 工具对返回的 JSON 结果进行字段提取：

```bash
# 调用大模型接口列出可用模型，并使用 jq 提取所有模型 ID
curl -s https://your-api-host/v1/models \
    -H "Authorization: Bearer sk-your-key-here" \
    | jq '.data[].id'
```

### 2. 局域网本地模型 API 测试 (以 172.16.0.1 为例)

当调试局域网内部部署的模型服务（如 Ollama、LocalAI 等）时：

```bash
# 测试局域网内 172.16.0.1 主机上的模型 API
curl -s https://172.16.0.1:8317/v1/models \
    -H "Authorization: Bearer your-api-key-1" \
    | jq '.data[].id'
```

> [!tip]
> `jq` 是一款强大的命令行 JSON 解析器。`.data[].id` 表示遍历 JSON 对象中 `data` 数组的每一项并输出其 `id` 属性。
